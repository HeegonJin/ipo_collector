직접 실행하기

종목별 시세는 KRX 약관상 제3자에게 줄 수 없어서, 실험실 앱은 각자 자기 KRX·DART 키로 로컬에서 돌립니다.

준비

git clone https://github.com/HeegonJin/ipo_collector.git
cd ipo_collector
python -m venv .venv && .venv/bin/pip install requests python-dotenv pyyaml pytest
cp .env.example .env     # KRX_API_KEY, DART_API_KEY 입력 (KRX 포털에서 서비스별 승인 필요)

데이터 수집 → 앱 실행

.venv/bin/python krx_api.py 20261029
.venv/bin/python dart_list.py 20220701 20261029
.venv/bin/python build_dart_registry.py 20220701 20261029 20261029
.venv/bin/python build_demand_mart.py
.venv/bin/python -m lab.server 20261029     # http://127.0.0.1:8765
cd lab/web && npm install && npm run build   # 화면 빌드(최초 1회)

앱은 내 컴퓨터(127.0.0.1)에서만 열립니다. “모의 운영” 탭에서 상장 일정을 직접 입력하고 일일 판단 작업을 실행합니다.

이 페이지는 KRX statistical information(한국거래소 통계정보)와 DART 공시로 만든 집계 결과이며, 모의투자 연구용입니다. 원천 데이터는 비상업 목적으로만 쓰고 제3자에게 제공하지 않습니다. 투자 권유가 아닙니다.
